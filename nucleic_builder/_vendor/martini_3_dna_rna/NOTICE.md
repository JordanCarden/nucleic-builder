# Vendored Martini 3 RNA and DNA-alpha notice

The RNA converter, experimental DNA-alpha converter, both mapping/topology
parameter sets, README, and regression assets in this directory are unmodified files from
`https://github.com/DanYev/Martini-3-DNA-RNA` at commit
`e761b7349fdf61dd485053c000dbb642f24ff9d8` (2026-07-21).

The upstream README declares the work GNU GPL v3 and older history records
`Copyright (c) 2025, DY`. The pinned snapshot has no separate license file or
source header, so this distribution conservatively applies `GPL-3.0-only` and
ships the full GPLv3 text as `LICENSE`. Wrapper validation, PDB normalization,
GRO writing, and consistency checks live outside this vendored directory.

The upstream README explicitly labels the DNA force field **alpha** and says a
publication is being prepared. This distribution preserves that status and
does not represent the DNA-alpha files as the published Martini 3 RNA model.

Scientific citation: D. Yangaliev and S. B. Ozkan, “Coarse-grained RNA model
for the Martini 3 force field,” *Biophysical Journal* 125(2), 445–456 (2026),
https://doi.org/10.1016/j.bpj.2025.07.034.
